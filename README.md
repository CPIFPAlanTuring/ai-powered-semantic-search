A large part of companies' critical information is stored in relational databases. Traditionally, searches in these databases are based on exact word matches, filters, or full-text indexes.

With embeddings and vector indexes, we can search by meaning while preserving the advantages of the relational model.

This project demonstrates how to implement semantic search in SQL Server 2025 using a local Ollama embedding model and the WideWorldImporters database.
